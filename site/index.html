常见问题

FloatPane 是什么?

FloatPane 是一款基于 Electron 的透明浮层浏览器,专为需要在工作时浏览网页的用户设计。窗口可以调节透明度、置顶显示、点击穿透,非常适合上班摸鱼场景。

支持哪些操作系统?

预编译包提供 Windows x64 和 Linux x64;macOS 仍可从源码构建,但不提供预编译 DMG。源码层面各平台功能一致。

是免费的吗?

完全免费,基于 MPL-2.0 开源协议发布,源码托管在 GitHub。

Windows 上托盘图标不显示怎么办?

1.0.0 版本已修复 Windows 托盘图标显示问题。请确保使用最新版本。如果仍有问题,请在 GitHub 提交 issue。

如何关闭 B 站视频自动网页全屏?

在菜单栏「显示」>「B站视频默认网页全屏」取消勾选即可。设置会自动保存,下次启动生效。

如何配置自动更新检测?

应用会在 userData 目录下读取 update-source.json 配置文件。可配置 GitLab 或 GitHub 作为更新源。启动后自动检查,也可通过菜单「显示」>「检查更新…」手动触发。

快速上手

下载安装

从 GitHub Releases 下载 Windows x64 安装程序或 Linux x64 AppImage。macOS 暂不提供预编译包,可从源码构建。

调节透明度

打开应用后，通过托盘菜单或快捷键调节窗口透明度。10% 几乎隐形，100% 完全不透明。

开启置顶与穿透

在托盘菜单中勾选「窗口置顶」和「点击穿透」。置顶让窗口始终在最上层，穿透让鼠标可以操作下方窗口。

导入书签和密码

支持从 Chrome / Safari 导入书签，从 Chrome 导出密码 CSV 文件后导入。在托盘菜单中选择对应选项即可。

配置自动更新（可选）

在 userData/update-source.json 中配置 GitLab 或 GitHub 更新源，应用启动后自动检查新版本。

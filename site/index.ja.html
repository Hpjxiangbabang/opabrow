opabrow 透明オーバーレイブラウザ

仕事中のこっそり閲覧ツール — 透明度を調整できるデスクトップオーバーレイブラウザ。最前面表示、クリック透過に対応し、仕事中でもいつでもウェブを閲覧できます。上司が来たらワンクリックで透明化。

主な機能

透明

ウィンドウ透明度調整

10% - 100% の範囲でウィンドウ透明度を自由に調整。仕事と閲覧を両立。ショートカットキーで素早く調整可能。

最前面

最前面表示 + クリック透過

ウィンドウを常に最前面に表示。クリック透過を有効にすると、マウスで下のウィンドウを直接操作でき、互いに干渉しません。

右クリック

完全な右クリックメニュー

選択テキストを直接コピー、Google/Bing で検索。リンクのコピーまたは開く操作に対応。貼り付け、全選択などの操作もサポート。

Bilibili

Bilibili 動画の Web ページ全画面

Bilibili 動画ページを自動検出し、ワンクリックで Web ページ全画面再生。手動クリック不要。メニューからこの機能をオフにできます。

更新

自動更新チェック

GitLab / GitHub での新バージョン自動検出に対応。起動時に自動でチェックし、更新があれば即座に通知します。

ブックマーク

ブックマーク / 履歴 / パスワード管理

Chrome / Safari のブックマークインポート、ローカル履歴、Chrome パスワードの CSV インポートと自動入力に対応。

ドラッグ

ドラッグ可能なアドレスバー

アドレスバーの幅を自由にドラッグ調整可能（最小 100px）。さまざまな使用シーンに対応。

スマホ

モバイルモードアクセス

ワンクリックでモバイル向け User-Agent に切替。スマホ版レイアウトでウェブを閲覧し、画面スペースを節約。

ダウンロード・インストール

よくある質問

opabrow とは何ですか?

opabrow は Electron ベースの透明オーバーレイブラウザで、仕事中にウェブを閲覧したいユーザーのために設計されています。ウィンドウの透明度調整、最前面表示、クリック透過に対応し、仕事中のこっそり閲覧シーンに最適です。

対応している OS は?

macOS (Apple Silicon + Intel)、Windows x64、Linux x64 に対応しています。全プラットフォームで機能は同一で、体験も同等です。

無料ですか?

完全無料です。MPL-2.0 オープンソースライセンスで公開されており、ソースコードは GitHub で公開されています。

Windows でトレイアイコンが表示されない場合は?

バージョン 1.0.0 で Windows のトレイアイコン表示問題を修正済みです。最新版をご利用ください。問題が続く場合は、GitHub で issue を提出してください。

Bilibili 動画の自動 Web ページ全画面をオフにするには?

メニューバーの「表示」>「Bilibili 動画をデフォルトで Web ページ全画面」のチェックを外してください。設定は自動的に保存され、次回起動時に反映されます。

自動更新チェックを設定するには?

アプリは userData ディレクトリ内の update-source.json 設定ファイルを読み取ります。GitLab または GitHub を更新ソースとして設定可能です。起動後に自動チェックしますが、メニュー「表示」>「更新を確認…」から手動で実行することもできます。

FloatPane 透明オーバーレイブラウザ

仕事中のこっそり閲覧ツール — 透明度を調整できるデスクトップオーバーレイブラウザ。最前面表示、クリック透過に対応し、仕事中でもいつでもウェブを閲覧できます。上司が来たらワンクリックで透明化。

主な機能

透明

ウィンドウ透明度調整

10% - 100% の範囲でウィンドウ透明度を自由に調整。仕事と閲覧を両立。ショートカットキーで素早く調整可能。

最前面

最前面表示 + クリック透過

ウィンドウを常に最前面に表示。クリック透過を有効にすると、マウスで下のウィンドウを直接操作でき、互いに干渉しません。

右クリック

完全な右クリックメニュー

選択テキストを直接コピー、Google/Bing で検索。リンクのコピーまたは開く操作に対応。貼り付け、全選択などの操作もサポート。

Bilibili

Bilibili 動画の Web ページ全画面

Bilibili 動画ページを自動検出し、ワンクリックで Web ページ全画面再生。手動クリック不要。メニューからこの機能をオフにできます。

更新

自動更新チェック

GitLab / GitHub での新バージョン自動検出に対応。起動時に自動でチェックし、更新があれば即座に通知します。

ブックマーク

ブックマーク / 履歴 / パスワード管理

Chrome / Safari のブックマークインポート、ローカル履歴、Chrome パスワードの CSV インポートと自動入力に対応。

ドラッグ

ドラッグ可能なアドレスバー

アドレスバーの幅を自由にドラッグ調整可能（最小 100px）。さまざまな使用シーンに対応。

スマホ

モバイルモードアクセス

ワンクリックでモバイル向け User-Agent に切替。スマホ版レイアウトでウェブを閲覧し、画面スペースを節約。

よくある質問

FloatPane とは何ですか?

FloatPane は Electron ベースの透明オーバーレイブラウザで、仕事中にウェブを閲覧したいユーザーのために設計されています。ウィンドウの透明度調整、最前面表示、クリック透過に対応し、仕事中のこっそり閲覧シーンに最適です。

対応している OS は?

macOS (Apple Silicon + Intel)、Windows x64、Linux x64 に対応しています。全プラットフォームで機能は同一で、体験も同等です。

無料ですか?

完全無料です。MPL-2.0 オープンソースライセンスで公開されており、ソースコードは GitHub で公開されています。

Windows でトレイアイコンが表示されない場合は?

バージョン 1.0.0 で Windows のトレイアイコン表示問題を修正済みです。最新版をご利用ください。問題が続く場合は、GitHub で issue を提出してください。

Bilibili 動画の自動 Web ページ全画面をオフにするには?

メニューバーの「表示」>「Bilibili 動画をデフォルトで Web ページ全画面」のチェックを外してください。設定は自動的に保存され、次回起動時に反映されます。

自動更新チェックを設定するには?

アプリは userData ディレクトリ内の update-source.json 設定ファイルを読み取ります。GitLab または GitHub を更新ソースとして設定可能です。起動後に自動チェックしますが、メニュー「表示」>「更新を確認…」から手動で実行することもできます。

使用シーン

💻

仕事中のこっそり閲覧

ウィンドウの透明度を30%に調整し、作業ウィンドウの上に最前面表示。上司が近づいたらワンクリックで透明度を下げ、仕事と閲覧を両立。

📺

動画を見ながら作業

クリック透過を有効にし、動画ウィンドウを最前面に浮かせてもマウス操作を妨げません。エディタで入力しながら動画を視聴できます。

📱

モバイル Web ページのテスト

ワンクリックでモバイル User-Agent に切り替え、モバイル向けレイアウトで Web ページをプレビュー。フロントエンド開発者のレスポンシブレイアウトのデバッグに最適。

🔍

素早い資料検索

テキストを選択して右クリックするだけで Google 検索可能、ウィンドウ切替不要。アドレスバーはドラッグで幅を調整でき、さまざまな Web ページに対応。

🎵

Bilibili 音楽・ポッドキャストのバックグラウンド再生

Bilibili 動画を自動で Web ページ全画面表示し、透明度とクリック透過を組み合わせることで、ポッドキャストを聴きながら作業でき、画面スペースも占有しません。

📖

オンラインでドキュメントを閲覧

ドキュメントページをオーバーレイとして最前面表示し、コードを書きながらドキュメントを参照。複数ウィンドウを切り替える手間が省けます。

クイックスタート

ダウンロード・インストール

GitHub Releases からお使いのプラットフォームのインストーラーをダウンロード。macOS は Applications にドラッグ、Windows は NSIS インストーラーを実行、Linux は AppImage を使用します。

透明度を調整

アプリを起動後、トレイメニューまたはショートカットキーでウィンドウの透明度を調整。10% でほぼ透明、100% で完全不透明になります。

最前面表示とクリック透過を有効化

トレイメニューで「ウィンドウを最前面に表示」と「クリック透過」にチェックを入れます。最前面表示でウィンドウが常に最前面に、クリック透過でマウスが下のウィンドウを操作できるようになります。

ブックマークとパスワードをインポート

Chrome / Safari からのブックマークインポート、Chrome からエクスポートしたパスワード CSV ファイルのインポートに対応。トレイメニューから該当オプションを選択するだけです。

自動更新を設定（任意）

userData/update-source.json で GitLab または GitHub の更新ソースを設定すると、アプリ起動後に新バージョンを自動的にチェックします。
